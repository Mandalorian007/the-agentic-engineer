# Transcripts

One file per post, named like the post (`YYYY-MM-DD-slug.md`), written by
`/create-content` before anything else is generated. It is the spoken or
dictated source with filler removed and technical terms resolved, and
otherwise in the speaker's own words and order. Every downstream artifact
(post, issue, surface kit) is written from it.

These are committed on purpose. They are the record of what was actually
said, and the voice reference the writers work from. Anything sensitive is
abstracted at clean time, with the user's say-so, before the file is
written.
