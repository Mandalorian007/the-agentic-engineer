I launched a blog on Blogger, then realized it wasn't going to work long-term. Too fragile, too many dependencies, not flexible enough.

So I did what any agentic engineer would do: I let my AI agents handle the migration.

Claude Code + Perplexity MCP + Firecrawl researched modern blogging platforms, compared frameworks, analyzed hosting options, and drafted a comprehensive migration plan.

The verdict? Next.js 15 + Vercel + shadcn/ui + Tailwind.

Total migration time: 4 hours for both the website AND the content pipeline.

This is the difference between agentic coding (AI writes functions) and agentic engineering (AI researches, plans, architects, and executes complete projects).

I defined the problem space and requirements. My agents did the research, planning, implementation, and validation.

The result? Simpler workflow (git push vs API calls), faster performance (no external APIs), better DX (hot-reload, TypeScript, local preview), and zero monthly costs.
