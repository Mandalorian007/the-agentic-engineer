Claude Code has evolved rapidly. What started as a simple AI coding assistant now has four distinct primitives—slash commands, MCPs, subagents, and skills.

The challenge? Knowing when to use each one.

• Context efficiency of each primitive

Key insights:

→ Slash commands are your workflow templates (high efficiency)
→ MCPs bring external tools and data (necessary but costly)
→ Subagents enable parallel execution without context pollution
→ Skills package local domain expertise (write them carefully)

The secret? Don't use these in isolation—compose them. A slash command can orchestrate MCPs, trigger subagents, and leverage skills. That's where the real power lives.
